# Gestion d'inventaire — installeurs

Ce dépôt ne contient **que les installeurs** de l'application de bureau « Gestion d'inventaire » (Windows 10/11,
64 bits). Le code source n'est pas publié ici.

**Installer la dernière version :**
[Installer-Gestion-Inventaire.exe](https://github.com/ThomasBruniquel/GestionInventaire-releases/releases/latest/download/Installer-Gestion-Inventaire.exe)

- Double-cliquez sur le fichier téléchargé : l'application s'installe pour l'utilisateur courant, sans droits
  administrateur, et s'ouvre. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur
  « Informations complémentaires » puis « Exécuter quand même » (l'installeur n'est pas signé).
- Les mises à jour se font ensuite depuis l'application (bouton « Mettre à jour »). Les données restent sur
  l'ordinateur et sont sauvegardées avant chaque mise à jour.
